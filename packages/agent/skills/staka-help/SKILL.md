# Staka Help

Provide guidance on using the Staka desktop environment.

## Keybinds

- **Super+A**: Open/close the AI panel
- **Super+Enter**: Open terminal
- **Super+D**: Application launcher
- **Super+1-9**: Switch to workspace 1-9
- **Super+Shift+1-9**: Move window to workspace 1-9
- **Super+Q**: Close focused window
- **Super+L**: Lock screen

## AI Panel

The AI panel (Super+A) gives you access to the Staka agent. You can:

- Ask questions about your organisation
- Search for colleagues
- Request help with tasks
- Use skills by typing `/skill-name`

## Skills

Skills are reusable instruction packs. View available skills with the `skills_list` tool. Load a skill's full instructions with `skill_view`.

## Organisation Features

- Machine activation via hardware ID
- Shared organisational memory
- Usage logging for admin visibility
